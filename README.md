# 스터디 프로모션 (Study Promotion)

> 한 칸씩 전진해서, 시험 날엔 퀸으로.

'프로모션'은 체스에서 폰이 마지막 칸에 닿아 퀸으로 바뀌는 '승급'을 뜻합니다. 시험 범위를 체스판처럼 펼쳐 놓고, 폰이 한 칸씩 전진하듯 범위를 하나씩 체크해서 시험 날엔 퀸이 되자는 뜻으로 지었습니다. 진행률은 8칸 위를 전진하는 폰으로 보이고, 범위를 다 끝내면 퀸으로 승급합니다.

시험 범위 화이트보드, 학습 계획, 집중 타이머, 플래시카드 복습, 통계를 한 곳에서 관리하는 웹 앱입니다.
설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 동작하고, 웹에 올리면 휴대폰·PC에 앱처럼 설치할 수 있습니다(PWA, 오프라인 지원).
데이터는 그 기기의 브라우저(localStorage)에 저장됩니다.

## 기능

- **홈**: 오늘 공부 시간과 목표 달성률, 남은 할 일, 복습 대기 카드, 연속 학습일, 시험별 D-day와 범위 진행률
- **범위 (시험 범위 화이트보드)**
  - 시험 → 과목·범주 카드 → 단원 → 세부 항목으로 범위를 나눠 넓은 보드에 배치
  - 범위 붙여넣기: 들여쓰기, `# 과목`, `- 단원` 목록을 붙여넣으면 카드가 자동으로 배치됨 (`[x]`는 완료로)
  - 항목 체크, 상위 체크 시 하위 전체 체크, 일부 완료 표시, 카드 완료 도장, 전체 진행률과 "하루 n개씩" 분량
  - ★ 중요 / ! 어려움 / ↻ 다시 보기 표시, 펜·형광펜·지우개로 직접 체크 표시, 노란 메모
  - 끌어서 이동, Ctrl+휠·핀치·버튼으로 확대, 한눈에 보기, 자동 정렬, 카드 끌기, 검색, 되돌리기
  - 항목에서 바로 타이머 시작·오늘 할 일로 보내기, 범위를 텍스트로 복사·저장, 인쇄
  - 단축키: V 선택, P 펜, H 형광펜, E 지우개, 0 한눈에 보기, / 검색, Ctrl+Z 되돌리기, 스페이스+끌기 이동
- **계획**: 과목·마감일·예상 시간이 있는 할 일, 필터, 과목 관리
- **타이머**: 뽀모도로(기본 25분/5분), 과목·범위별 자동 기록, 완료 알림음. 집중이 끝나면 스톱워치로 계속 / 휴식 / 같은 타이머 다시 / 끄기 중에서 고름
- **스톱워치**: 과목을 눌러 공부 시간을 재고 멈추면 기록. 홈의 ‘공부 시작하기’로 과목과 할 일을 골라 바로 시작
- **타임테이블**: 공부한 시간이 하루 시간표(한 줄 = 한 시간, 한 칸 = 10분)에 과목 색으로 칠해짐. 재는 중인 시간도 바로 표시, 날짜별로 보기
- **복습**: 덱과 카드, SM-2 간격 반복(다시/어려움/보통/쉬움), 여러 장 일괄 추가 (스페이스, 1~4 단축키)
- **통계**: 최근 7일 공부 시간, 과목별 누적 시간, 최근 집중 기록, 설정, JSON 백업/복원
- 화면 밝기(자동/밝게/어둡게), 테마 색(청록/핑크), 휴대폰 화면 지원
- **기록 지키기**: 앱이 업데이트될 때, 기록을 통째로 바꾸기 전(백업 불러오기·계정 기록 받기·초기화·되돌리기), 하루에 한 번 이 기기(IndexedDB)에 자동 백업. 계정·설정 › 백업 › 자동 백업에서 되돌리기. 새 버전에서 생긴 항목은 옛 버전이 저장해도 지우지 않고, 읽지 못한 기록은 원본을 따로 보관, 저장에 실패하면 알림
- **이스터에그**: 앱 소개의 비밀 입력칸. 베타테스트에 피드백을 준 사람이 이름을 넣으면 반영된 피드백이 나타남 (이름은 해시로만 저장, `node tools/egg-key.js 이름`으로 추가)

## 실행과 설치

```bash
open index.html          # 그냥 파일 열기 (설치·오프라인 기능 제외 모두 동작)
npm start                # http://localhost:8080 — 설치형 앱 기능까지 확인
npm run build            # dist/studypromotion.html(파일 하나 버전), dist/web/(웹 호스팅용)
```

`dist/web/` 폴더를 GitHub Pages, Netlify 같은 곳에 올리면 주소가 생기고,
안드로이드·PC 크롬/엣지에서는 **앱 설치** 버튼, 아이폰에서는 Safari 공유 → **홈 화면에 추가**로 설치됩니다.

## 테스트

```bash
npm test                 # 알고리즘·범위 트리·저장소 단위 테스트 (Node 18+)
npm run test:e2e         # 브라우저 시나리오 테스트 (Playwright 필요)
```

## 구글 계정 연동 켜기

설정 화면의 **구글 계정 연동**은 공부 기록을 내 구글 드라이브의 `studypromotion-data.json` 파일 하나에 저장하고, 다른 기기에서 불러옵니다. 권한은 `drive.file`이라 이 앱이 만든 파일 말고는 드라이브의 다른 파일을 볼 수 없습니다.

켜려면 구글 OAuth 클라이언트 ID가 필요합니다 (공개돼도 되는 값입니다).

1. https://console.cloud.google.com 에서 새 프로젝트를 만듭니다.
2. API 및 서비스 → 라이브러리 → **Google Drive API** 사용.
3. Google 인증 플랫폼(OAuth 동의 화면) → 앱 이름·이메일 입력, 대상은 **외부**. 대상 → 테스트 사용자에 쓸 구글 계정을 추가합니다.
4. 클라이언트 → 클라이언트 만들기 → **웹 애플리케이션**, 승인된 JavaScript 원본에 `https://mjleo6278-thecreater.github.io` 추가.
5. 만들어진 클라이언트 ID를 `js/gsync.js` 맨 위 `CLIENT_ID`에 넣고 main에 올리면 자동 배포됩니다.
