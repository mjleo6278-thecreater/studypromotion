# 스터디 프로모션 (Study Promotion)

> 한 칸씩 전진해서, 시험 날엔 퀸으로.

'프로모션'은 체스에서 폰이 마지막 칸에 닿아 퀸으로 바뀌는 '승급'을 뜻합니다. 시험 범위를 체스판처럼 펼쳐 놓고, 폰이 한 칸씩 전진하듯 범위를 하나씩 체크해서 시험 날엔 퀸이 되자는 뜻으로 지었습니다. 진행률은 8칸 위를 전진하는 폰으로 보이고, 범위를 다 끝내면 퀸으로 승급합니다.

시험 범위 화이트보드, 학습 계획, 집중 타이머, 플래시카드 복습, 통계를 한 곳에서 관리하는 웹 앱입니다.
설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 동작하고, 웹에 올리면 휴대폰·PC에 앱처럼 설치할 수 있습니다(PWA, 오프라인 지원).
데이터는 그 기기의 브라우저(localStorage)에 저장됩니다.

## 기능

- **홈**: 오늘 공부 시간과 목표 달성률, 남은 할 일, 복습 대기 카드, 연속 학습일, 시험별 D-day와 범위 진행률
- **범위 (시험 범위 화이트보드)**
  - 시험 → 과목·범주 카드 → 단원 → 세부 항목으로 범위를 나눠 넓은 보드에 배치
  - 범위 붙여넣기: 들여쓰기, `# 과목`, `- 단원` 목록을 붙여넣으면 카드가 자동으로 배치됨 (`[x]`는 완료로)
  - 항목 체크, 상위 체크 시 하위 전체 체크, 일부 완료 표시, 카드 완료 도장, 전체 진행률과 "하루 n개씩" 분량
  - ★ 중요 / ! 어려움 / ↻ 다시 보기 표시, 펜·형광펜·지우개로 직접 체크 표시, 노란 메모
  - 끌어서 이동, Ctrl+휠·핀치·버튼으로 확대, 한눈에 보기, 자동 정렬, 카드 끌기, 검색, 되돌리기
  - 항목에서 바로 타이머 시작·플래너에 넣기(오늘·내일·고른 날), 범위를 텍스트로 복사·저장, 인쇄
  - 단축키: V 선택, P 펜, H 형광펜, E 지우개, 0 한눈에 보기, / 검색, Ctrl+Z 되돌리기, 스페이스+끌기 이동
- **스터디 플래너 (v3.7, 예전 ‘계획’ 탭)**: 날짜마다 할 일(과목·예상 시간·매일/요일 반복)을 적고 체크. 하루 보기(주간 띠, 그날 목표·진행률·시험 D-day, 할 일, 지난 날 못 한 일 ‘오늘로 가져오기’, 타임테이블 띠·일정, 하루 돌아보기 메모)와 주간 보기, 달력 창. ⋯ 메뉴로 공부 시작·내일로 미루기·다른 날로 옮기기·공부할 시각 정하기. ‘범위에서 고르기’로 시험 범위 항목을 아무 날에 넣으면 할 일과 범위가 한 몸(어느 쪽을 체크해도 둘 다, 공부 시간은 한 번만). 할 일의 `due`가 플래너의 날짜(하는 날), 목표·메모는 `planner` { 'YYYY-MM-DD': { goal, memo } }. 계산은 js/plan.js, 화면은 js/planner.js. 홈의 ‘오늘 할 일’은 플래너의 오늘 칸
- **타이머**: 뽀모도로(기본 25분/5분), 과목·범위별 자동 기록, 완료 알림음. 집중이 끝나면 스톱워치로 계속 / 휴식 / 같은 타이머 다시 / 끄기 중에서 고름
- **스톱워치**: 과목을 눌러 공부 시간을 재고 멈추면 기록. 홈의 ‘공부 시작하기’로 과목과 할 일(또는 시험 범위 항목)을 골라 바로 시작
- **일정·주간 스케줄 표 (v2.11)**: 공부 일정(과목 색)과 다른 일정(약속·운동, 회색)을 날짜·시각·반복(한 번만/매일/매주 요일, 끝나는 날)으로 넣기. 타임테이블 하루 보기에 일정은 점선으로 겹치고, ‘주간’은 월~일 시간표(옅은 칸 = 일정, 오른쪽 줄 = 실제 공부, ✓ = 계획대로). 끝난 일정은 ‘계획대로 했어요’로 바로 기록, 지금 일정은 홈·공부 시작하기에서 바로 시작, 플래너 할 일의 ⋯ › 공부할 시각 정하기로 시간 정하기. 데이터는 `events` 목록(js/schedule.js 설명), 화면 없이 고치는 `Events.add/update/remove`
- **타임테이블**: 공부한 시간이 하루 시간표(한 줄 = 한 시간, 한 칸 = 10분)에 과목 색으로 칠해짐. 재는 중인 시간도 바로 표시, 날짜별로 보기. 기록 못 한 공부는 칸을 누르거나 ‘＋ 공부 시간 추가’로 몇 시부터 몇 시까지 직접 적기(겹치면 알림, 하루 경계를 넘으면 나눠 기록)
- **복습**: 덱과 카드, SM-2 간격 반복(다시/어려움/보통/쉬움), 여러 장 일괄 추가 (스페이스, 1~4 단축키)
- **링크로 카드 가져오기 (v3.5)**: 카드가 담긴 링크를 누르면 ‘카드 N장을 추가할까요?’ 창에서 덱을 골라 넣음. 같은 덱에 이미 있는 카드는 뺌. 단어장 사진을 Claude에게 보내 링크를 받는 용도 (아래 [링크로 카드 가져오기](#링크로-카드-가져오기))
- **기능과 탭 편집 (v3.6)**: 계정·설정 › 기능과 탭 편집에서 탭(홈 제외)·타이머 안 기능(집중 타이머·스톱워치·폰 잠금)·세컨드 버튼을 켜고 끄고, 탭과 홈 화면 칸의 순서를 꾹 눌러 끌어 바꿈. 꺼도 기록은 그대로. `settings.layout`({ tabs, home, off })에 저장되어 계정 동기화·백업에 함께 들어감. 기능 목록은 js/features.js `LIST` 하나 (새 탭은 여기에 한 줄 넣으면 편집 화면·탭 막대에 나타남)
- **통계**: 최근 7일 공부 시간, 과목별 누적 시간, 최근 집중 기록, 설정, JSON 백업/복원
- 화면 밝기(자동/밝게/어둡게), 테마 색(청록/핑크), 휴대폰 화면 지원
- **기록 지키기**: 앱이 업데이트될 때, 기록을 통째로 바꾸기 전(백업 불러오기·계정 기록 받기·초기화·되돌리기), 하루에 한 번 이 기기(IndexedDB)에 자동 백업. 계정·설정 › 백업 › 자동 백업에서 되돌리기. 새 버전에서 생긴 항목은 옛 버전이 저장해도 지우지 않고, 읽지 못한 기록은 원본을 따로 보관, 저장에 실패하면 알림
- **이스터에그**: 앱 소개의 비밀 입력칸. 피드백이나 아이디어를 준 사람이 이름을 넣으면 반영된 내용이 나타남 (이름은 해시로만 저장, `node tools/egg-key.js 이름 이름만`으로 추가. 이름만 넣는 업데이트는 버전 번호·업데이트 소식에 적지 않고 `sw.js` CACHE만 올림, 버전 번호가 그대로면 '새 버전' 알림도 안 뜸). 비밀 단어로 함께 공부하는 영상(v3.4), '벽 튕기기' 공 게임(v3.8, `js/bounce.js`: 기기 안 사진을 동그랗게 잘라 공 얼굴로 쓰고, 사진은 그 기기의 localStorage에만 저장)도 열림. v3.9부터 게임 기록의 전체 순위는 AI 도우미와 같은 서버(`worker/`의 `/bounce`)에 별명과 함께 한 사람에 한 줄씩 저장

## 실행과 설치

```bash
open index.html          # 그냥 파일 열기 (설치·오프라인 기능 제외 모두 동작)
npm start                # http://localhost:8080 — 설치형 앱 기능까지 확인
npm run build            # dist/studypromotion.html(파일 하나 버전), dist/web/(웹 호스팅용)
```

`dist/web/` 폴더를 GitHub Pages, Netlify 같은 곳에 올리면 주소가 생기고,
안드로이드·PC 크롬/엣지에서는 **앱 설치** 버튼, 아이폰에서는 Safari 공유 → **홈 화면에 추가**로 설치됩니다.

## 테스트

npm test                 # 알고리즘·범위 트리·저장소 단위 테스트 (Node 18+)

## 링크로 카드 가져오기

단어장·교과서 사진을 Claude 같은 AI에게 보내 "스터디 프로모션 카드로 만들어 줘"라고 하면, AI가 용어와 뜻을 읽어 아래 형식의 링크를 만들어 줍니다.
링크를 누르면 앱이 열리면서 넣을 카드와 덱을 보여 주고, 확인하면 그 덱에 들어갑니다(로그인했으면 계정에도 저장). 서버를 거치지 않고 주소의 `#` 뒷부분만으로 카드를 건넵니다(`#` 뒤는 서버로 가지 않음).

### 형식 1: 글자 그대로 (기본, 손으로 써도 됨)

```
https://mjleo6278-thecreater.github.io/studypromotion/#cards&deck=스페인어+3과&c=hola~안녕&c=adiós~잘+가&c=comer+%28v.%29~먹다
```

- `#cards`로 시작합니다. `deck=`은 덱 이름(없으면 ‘가져온 카드 날짜’), `c=` 하나가 카드 한 장이고 `앞면~뒷면`입니다(첫 `~`에서 나눔).
- 띄어쓰기는 `+`. 한글·악센트(á ñ ¿ ¡)·쉼표·물음표·마침표·작은따옴표·`/`·`:`·`;`·`-`는 그대로 씁니다.
- 아래 글자만 바꿔 적습니다.

  | 글자 | `+` | `&` | `#` | `%` | `~` | `(` | `)` | `"` | `<` `>` | `[` `]` | `\` |
  |---|---|---|---|---|---|---|---|---|---|---|---|
  | 적는 법 | `%2B` | `%26` | `%23` | `%25` | `%7E` | `%28` | `%29` | `%22` | `%3C` `%3E` | `%5B` `%5D` | `%5C` |

- 줄바꿈·연속 빈칸은 빈칸 하나로 합쳐집니다. 앞면 300자, 뒷면 500자, 한 링크에 1000장까지.
- 같은 링크 안에서 겹친 카드는 한 장만, 고른 덱에 이미 있는 카드(앞·뒤가 같으면, 대소문자 무시)는 빼고 넣습니다. 그래서 긴 목록을 링크 여러 개로 나눠 같은 덱 이름으로 보내도 됩니다.
- 너그럽게 읽기: `~` 대신 ` - `나 탭으로 나눠도, 어딘가에서 링크 전체가 `%XX`로 바뀌어도 읽습니다.
- 대화창에 보낼 때는 `[카드 12장 앱에 넣기](링크)`처럼 마크다운 링크로 감싸면 끝 글자가 잘리지 않습니다.

### 형식 2: 압축 (아주 긴 목록을 프로그램으로 만들 때)

```
https://mjleo6278-thecreater.github.io/studypromotion/#cards&z=<base64url(deflate-raw(UTF-8 JSON))>
JSON: {"deck":"덱 이름","cards":[["앞면","뒷면"], ...]}
```

브라우저의 `DecompressionStream('deflate-raw')`로 풉니다(크롬 103·사파리 16.4·파이어폭스 113 이상). 200장 기준으로 형식 1의 3분의 1보다 짧지만, AI가 대화창에 옮겨 적다 한 글자만 틀려도 통째로 못 읽으므로 AI가 직접 쓸 때는 형식 1을 권합니다.

### 링크 만들기 도구

```bash
printf 'hola\t안녕\nadiós\t잘 가\n' | python3 tools/card_link.py --deck "스페인어 3과"
python3 tools/card_link.py --zip cards.json     # [["앞","뒤"], ...] 또는 {"deck": "...", "cards": [...]}
```

앱 쪽 코드는 `js/cardlink.js`(`CardLink.read/build/buildZip`), 시험은 `tests/cardlink.test.js`(파이썬 도구와 글자 하나까지 같은지 포함)·`tests/cardlink.e2e.js`.

## 구글 계정 연동 켜기

설정 화면의 **구글 계정 연동**은 공부 기록을 내 구글 드라이브의 `studypromotion-data.json` 파일 하나에 저장하고, 다른 기기에서 불러옵니다. 권한은 `drive.file`이라 이 앱이 만든 파일 말고는 드라이브의 다른 파일을 볼 수 없습니다.

켜려면 구글 OAuth 클라이언트 ID가 필요합니다 (공개돼도 되는 값입니다).

1. https://console.cloud.google.com 에서 새 프로젝트를 만듭니다.
2. API 및 서비스 → 라이브러리 → **Google Drive API** 사용.
3. Google 인증 플랫폼(OAuth 동의 화면) → 앱 이름·이메일 입력, 대상은 **외부**. 대상 → 테스트 사용자에 쓸 구글 계정을 추가합니다.
4. 클라이언트 → 클라이언트 만들기 → **웹 애플리케이션**, 승인된 JavaScript 원본에 `https://mjleo6278-thecreater.github.io` 추가.
5. 만들어진 클라이언트 ID를 `js/gsync.js` 맨 위 `CLIENT_ID`에 넣고 main에 올리면 자동 배포됩니다.
