# 업데이트 컷씬 (시제품)

업데이트마다 "이 기능을 왜 만들었나"를 짧은 3D 컷씬으로 보여 주려는 시제품이다.
아직 앱에 연결하지 않았다. `tools/build.js`는 이 폴더를 배포본에 넣지 않는다.

- `character.html` : 개발자 폰 캐릭터 돌려 보기·표정 보기
- `index.html` : 컷씬 #1 "샤워하다 생긴 기능" (말로 외우는 단어장 이야기)

## 설계 (만들기 전에 정한 것)

**목표**: 개발자를 투영한 복셀(픽셀 느낌 3D) 체스 폰 캐릭터와, 그 캐릭터가 겪은 불편에서 기능이 나오는 30초 안팎의 컷씬.

**우선순위** (부딪히면 위가 이김)
1. 자막을 안 읽어도 그림만으로 이야기가 읽힌다 (샤워 중 → 손에 거품 → 화면이 안 눌림 → 말로 하자 → 말하니 넘어감).
2. 캐릭터가 귀엽고 표정이 읽힌다 (기본·깜빡·답답 ><·번뜩·신남).
3. 폰에서 부드럽게 돈다.
4. 효과(물줄기·김·거품·반짝임·소리)는 그다음.

**제약**
- 아무것도 내려받지 않는다: 3D는 WebGL을 직접 쓰고(라이브러리 없음), 자막은 앱에 이미 있는 Pretendard를 작은 크기로 그린 뒤 픽셀로 키운다, 소리는 Web Audio로 합성한다.
- 참고 사진(복셀 게임들)은 분위기·화풍만 참고한다. 그 캐릭터·게임을 따라 그리지 않는다.
- 앱 main 합치기·배포는 사용자 동의 전에는 하지 않는다.

**숫자 목표**
- 화면: 폰 세로 360×640, 390×844, 가로 844×390, 태블릿 768×1024에서 캐릭터·폰 화면·자막이 잘리지 않는다.
- 자막: 한 줄 13자 이하, 두 줄 이하. 글자 높이 화면에서 20px 이상(360 폭). 한 자막은 최소 2.4초 보인다.
- 길이: 28~34초, 장면 6개.
- 그리기: 삼각형 6만 개 이하, 한 프레임 그리기 호출 120번 이하.
- 단추(건너뛰기·소리·다시 보기): 44×44px 이상. 건너뛰기는 언제 눌러도 끝 화면으로 간다.
- 파일: 컷씬 코드 전체 150KB 이하, 외부 요청 0개(글꼴 제외).

**검증**
- 시간을 넣으면 그 순간을 그리는 시험용 고리 `Cutscene.renderAt(t)` → 같은 시각은 늘 같은 그림.
- Playwright로 폰 폭마다 장면별 스크린샷, 시작·건너뛰기·다시 보기·소리 단추를 눌러 본다.
- 소리는 같은 일정으로 오프라인 렌더링해서 소리 파일이 비어 있지 않은지 확인하고 영상에 붙인다.
- 화면 비평가 서브에이전트: 코드와 내 설명 없이 스크린샷과 참고 사진만 보고 ① 무슨 이야기로 읽히는지 ② 고칠 점 5개까지. 라운드마다 새 비평가.

**끝 조건**: 비평가가 낸 중요한 고칠 점이 남지 않거나 3라운드를 마침 + 위 화면 크기 스크린샷 + 영상(MP4)·GIF.
